A program that writes one warm, funny, heartfelt family scene — one line, 167 characters: Mom says "one more episode", Dad falls asleep on the remote, the kids build a blanket fort over him, and nobody has the heart to change the channel. It picks the strongest scene from a shortlist with a small deterministic scorer that follows the judge's brief.

## Run it

```sh
python3 main.py
```

It writes the scene to `/output/entry.txt` (override with the `ENTRY_OUTPUT` environment variable).
